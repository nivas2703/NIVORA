# NIVORA — The Nivas Universe

Complete editable Antigravity-ready project.

## Run in Antigravity
1. Open the `NIVORA` folder.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the Vite local URL.

## Production build
Run `npm run build`; deploy the generated `dist/` folder.

## Structure
`index.html` · `css/style.css` · `js/script.js` · `assets/` · `package.json` · `vite.config.js`
